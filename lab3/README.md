# Лабораторная работа 3 — фрактал «Симонброт»

Графическое приложение на Python, NumPy и pygame для варианта 13.
`main.py` запускает полную версию, а `nr5.py`–`nr10.py` — отдельные уровни
по критериям оценивания. Размер окна фиксирован: 900 × 740 пикселей;
область изображения фрактала — 900 × 560 пикселей.

## Уточнение формулы

В задании указан **«рациональный фрактал „Симонброт“»**, но формула не дана.
В программе выбран документированный **SimonBrot 4th**:

```text
z₀ = 0
zₙ₊₁ = zₙ² · (|Re(zₙ)| + i·|Im(zₙ)|)² + c
```

Источник формулы: [руководство Kalles Fraktaler, SimonBrot 4th](https://mathr.co.uk/kf/manual.html#simonbrot-4th).
Здесь `c` — комплексная координата пикселя, `z` — текущее значение итерации,
`i² = −1`. Модули берутся отдельно от действительной и мнимой частей.

У этой формулы нет знаменателя: название «рациональный» из задания
не подтверждается выбранным определением. Если преподаватель подразумевает
другую формулу, её необходимо уточнить перед защитой. Выбранное определение
явно указано в программе и документации.

## Установка и запуск

Команды выполняются из каталога `lab3`. Нужен Python 3 с поддержкой NumPy
и pygame; создание виртуального окружения позволяет установить зависимости отдельно.

macOS / Linux:

```bash
cd lab3
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py --iterations 300
```

Windows, PowerShell:

```powershell
cd lab3
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py --iterations 300
```

Windows, командная строка `cmd`: вместо команды активации PowerShell
используйте `.venv\Scripts\activate.bat`. Можно запускать без активации:
`.venv\Scripts\python.exe main.py --iterations 300`.

Варианты запуска на macOS / Linux:

```bash
.venv/bin/python nr5.py
.venv/bin/python nr6.py --iterations 250
.venv/bin/python nr7.py --iterations 250
.venv/bin/python nr8.py --iterations 300
.venv/bin/python nr9.py --iterations 300
.venv/bin/python nr10.py --iterations 300
.venv/bin/python main.py --grade 8 --iterations 300
```

На уровнях 6–10, если `--iterations` не указан, программа спрашивает число
итераций в консоли перед открытием окна. Пустой ответ выбирает 200.
В `nr5.py` используется заданная в коде константа 200.

## Соответствие критериям

Каждый следующий уровень включает возможности предыдущего.

| Уровень | Файл | Возможности |
| --- | --- | --- |
| 5 | `nr5.py` | Чёрно-белый фрактал, фиксированное окно, 200 итераций из кода. |
| 6 | `nr6.py` | Центрирование, одинаковый масштаб по осям, ввод итераций до запуска. |
| 7 | `nr7.py` | Цвет по номеру выхода за радиус 2, фоновый расчёт, сброс вида клавишей `R`. |
| 8 | `nr8.py` | Плавная палитра из четырёх оттенков, изменение итераций во время работы. |
| 9 | `nr9.py` | Интерактивное увеличение вокруг курсора по левому клику. |
| 10 | `nr10.py` | Масштаб, центр и итерации на экране; орбита точки и экспорт результата. |

Дополнительное индивидуальное задание преподавателем не задано.
В качестве предложения реализованы исследование орбиты и сохранение результата
в PNG вместе с параметрами в JSON. Это предложение нужно согласовать
с преподавателем; наличие функций само по себе не гарантирует оценку 10.

## Управление

| Действие | Клавиша / мышь | Доступно с уровня |
| --- | --- | --- |
| Закрыть программу | `Esc` или кнопка закрытия окна | 5 |
| Вернуть исходный центр и масштаб | `R` | 7 |
| Переключить цветной / чёрно-белый режим | `B` | 7 |
| Добавить 50 итераций | `+` или `↑` | 8 |
| Убрать 50 итераций | `−` или `↓` | 8 |
| Увеличить в 2 раза вокруг выбранной точки | Левая кнопка мыши на фрактале | 9 |
| Уменьшить в 2 раза | Правая кнопка мыши на фрактале | 9 |
| Выбрать точку `c` для исследования орбиты | Средняя кнопка мыши на фрактале | 10 |
| Показать / скрыть орбиту | `O` | 10 |
| Сохранить PNG и JSON | `S` | 10 |

`R` сохраняет выбранное число итераций. Масштаб ограничен диапазоном
от 1 до 10¹². Клики по панели параметров не меняют область изображения.
Подсказки в окне соответствуют выбранному уровню.

Сохранённые файлы появляются в `lab3/screenshots`. JSON хранит параметры
показанного изображения, поэтому их можно использовать в отчёте вместе с PNG.

## Как работает алгоритм

1. Каждый пиксель переводится в число `c = Re(c) + i·Im(c)`.
   Шаг координат одинаков по горизонтали и вертикали: изображение не растягивается.
2. Для точки запускается последовательность с `z₀ = 0` по формуле выше.
3. После каждого шага проверяется `Re(z)² + Im(z)² > 4`.
   При выполнении условия расчёт этой точки прекращается, сохраняется номер шага.
4. Точки, не вышедшие за радиус 2 до лимита, окрашиваются в чёрный цвет.
   В чёрно-белом режиме внешние точки белые. На уровне 7 цвет внешней точки
   определяется целым номером итерации; начиная с уровня 8 используется
   сглаженное значение и интерполяция между четырьмя оттенками палитры.
5. Расчёт выполняется в фоновом рабочем потоке, а главный поток обрабатывает
   события окна. При изменении параметров устаревший расчёт отменяется.

Чёрный цвет означает только, что точка не вышла за заданное число шагов;
конечное число итераций не доказывает принадлежность бесконечному множеству.
Вычисления используют числа двойной точности. При большом приближении их
точность ограничивает детализацию; увеличение лимита итераций не устраняет
ошибки округления координат.

Орбита показывает последовательные значения `z₀, z₁, z₂, …` для выбранного `c`.
Она помогает увидеть, остаётся ли последовательность ограниченной в пределах
лимита или быстро покидает круг радиуса 2.

## Структура файлов и проверка

- `fractal.py` — формула, преобразование координат, расчёт и окраска.
- `app.py` — окно pygame, обработка действий и фоновый расчёт.
- `main.py` — запуск и параметры командной строки.
- `nr5.py`–`nr10.py` — запуск выбранного уровня.
- `requirements.txt` — зависимости.
- `test_fractal.py`, `test_app.py` — автоматические проверки.
- `repo/` — ранее добавленные примеры Мандельброта; приложение их не использует.

Запуск проверок **из корня репозитория** на macOS / Linux:

```bash
lab3/.venv/bin/python -m unittest discover -s lab3 -p 'test_*.py'
```

Для демонстрации запустите `nr10.py`, измените число итераций, увеличьте
интересную область левым кликом, выберите точку средней кнопкой,
покажите орбиту и сохраните изображение клавишей `S`.
