# Лабораторная работа 4: основы 3D-графики в OpenGL

Python + pygame + PyOpenGL. Окно 1000 на 760 пикселей, настоящий
контекст OpenGL 2.1, двойная буферизация и буфер глубины 24 бита.
`main.py` запускает полную версию. Отдельные уровни, как в предыдущих
лабораторных, находятся в `nr5.py`–`nr10.py`.

## Установка и запуск

Рекомендуется Python 3.11–3.13. Команды из корня репозитория, macOS/Linux:

```bash
python3 -m venv lab4/.venv
lab4/.venv/bin/python -m pip install -r lab4/requirements.txt
lab4/.venv/bin/python lab4/main.py
```

На этом компьютере окружение `lab4/.venv` уже создано, зависимости установлены.
Для повторного запуска достаточно последней команды.

Windows, PowerShell:

```powershell
py -3.11 -m venv lab4/.venv
lab4/.venv/Scripts/python.exe -m pip install -r lab4/requirements.txt
lab4/.venv/Scripts/python.exe lab4/main.py
```

Нужны драйвер видеокарты и поддержка настольного OpenGL 2.1.
Используется учебный конвейер совместимости: `glBegin`, `glMatrixMode`,
`glLight`. Это позволяет непосредственно изучать матрицы, нормали и освещение.

## Уровни по критериям оценивания

| Оценка | Файл | Возможности |
| --- | --- | --- |
| 5 | `nr5.py` | Создание окна и контекста OpenGL; каркас куба одного цвета. |
| 6 | `nr6.py` | Шесть цветов граней куба; включён `GL_DEPTH_TEST`. |
| 7 | `nr7.py` | Перспектива через `gluPerspective`; непрерывное вращение вокруг Y. |
| 8 | `nr8.py` | Домик из кубов и треугольной призмы; вращение по X/Y/Z и движение камеры клавишами. |
| 9 | `nr9.py` | Точечный свет, единичные нормали, диффузное и зеркальное освещение; обзор зажатой кнопкой мыши. |
| 10 | `nr10.py` | PNG-текстура на стенах; независимая анимация лопастей мельницы и двери вокруг петли. |

Каждый следующий уровень включает предыдущие возможности. На уровнях 5–6
проекция ортогональная, начиная с 7 — перспективная. Буфер глубины включён
во всех версиях. Начиная с 8 каркас можно включить клавишей `F`.

Примеры запуска из корня репозитория:

```bash
lab4/.venv/bin/python lab4/nr5.py
lab4/.venv/bin/python lab4/nr6.py
lab4/.venv/bin/python lab4/nr7.py
lab4/.venv/bin/python lab4/nr8.py
lab4/.venv/bin/python lab4/nr9.py
lab4/.venv/bin/python lab4/nr10.py
lab4/.venv/bin/python lab4/main.py --grade 9
```

Индивидуальное задание в условии не уточнено. В качестве предложения
реализована **иерархическая анимация**: дверь поворачивается вокруг петли,
а лопасти мельницы — вокруг общего центра независимо от вращения сцены.
Это дополнительное задание нужно согласовать с преподавателем.

Ручное вращение и начало обзора мышью приостанавливают автоматическое
вращение сцены. `Space` запускает его снова. Дверь и мельница анимируются
независимо от этой паузы. Движение зависит от времени кадра, а не от FPS.
При потере фокуса зажатые клавиши сбрасываются.

Снимки сохраняются в `lab4/screenshots`. Для получения кадра с автоматическим
завершением программы:

```bash
lab4/.venv/bin/python lab4/main.py --frames 60 --screenshot lab4/screenshots/demo.png
```

## Что объяснить на защите

1. `pygame.display.set_mode(..., OPENGL | DOUBLEBUF)` создаёт окно
   и контекст. Кадр завершается обменом буферов `pygame.display.flip()`.
2. Перед каждым кадром очищаются цвет и глубина.
   `glEnable(GL_DEPTH_TEST)` и `glDepthFunc(GL_LEQUAL)` позволяют ближним
   поверхностям закрывать дальние независимо от порядка рисования.
3. Матрица `GL_PROJECTION` задаёт ортогональную или перспективную проекцию.
   Соотношение сторон берётся по области сцены, без панелей текста.
4. `gluLookAt` задаёт камеру. `glTranslatef`, `glRotatef`, `glScalef`
   задают положение, поворот и размеры объекта.
   `glPushMatrix`/`glPopMatrix` изолируют преобразования частей сцены.
5. Нормаль вычисляется как нормализованное векторное произведение двух
   рёбер грани. Порядок вершин задаёт направление наружу.
   `GL_NORMALIZE` корректирует длину преобразованной нормали после масштабирования.
6. `GL_LIGHT0` — точечный источник в мировой системе координат.
   `GL_COLOR_MATERIAL` сохраняет цвета граней при включённом свете.
   Материал имеет зеркальную составляющую и коэффициент блеска.
7. `assets/wall.png` — локальная растровая текстура кладки, созданная
   процедурно для этой работы. Она читается через `pygame.image.load`,
   загружается `glTexImage2D`, привязывается `glBindTexture`.
   Каждой вершине назначается координата UV через `glTexCoord2fv`.
8. У двери своя матрица: перенос к петле, поворот, перенос к центру полотна,
   масштабирование. У лопастей общий вращающийся родительский узел.
9. Текстовые панели рисуются отдельным ортогональным проходом.
   После него матрицы и состояния OpenGL восстанавливаются.

## Файлы и проверки

- `app.py` — контекст, рисование, свет, текстура, панели и события.
- `geometry.py` — вершины, нормали и UV куба и крыши.
- `state.py` — камера, повороты и анимация.
- `main.py`, `nr5.py`–`nr10.py` — точки запуска.
- `assets/wall.png` — изображение текстуры стен.
- `test_scene.py` — проверки геометрии, анимации и управления.
- `test_opengl.py` — проверки настоящего OpenGL, глубины и снимков.

Проверки без создания окна:

```bash
lab4/.venv/bin/python -m unittest discover -s lab4 -p 'test_*.py'
```

Полные проверки с настоящим графическим контекстом (macOS/Linux):

```bash
RUN_OPENGL_TESTS=1 lab4/.venv/bin/python -m unittest discover -s lab4 -p 'test_*.py'
```

В PowerShell перед той же командой задайте `$env:RUN_OPENGL_TESTS="1"`.
Эти проверки создают скрытое окно OpenGL; драйвер `SDL_VIDEODRIVER=dummy`
для них не подходит.
